# ShuttleStats

Real-time badminton match tracker + performance analytics. This is a **private install page**
for our group — not on the App Store or Play Store. Nothing you record leaves your device unless
you choose to share it.

## Install on Android

1. On your phone, scan the QR code you were given (or open the link below).
2. Download **ShuttleStats.apk**.
3. Tap the downloaded file. If Android warns about installing from an unknown source, tap
   **Settings → Allow from this source**, then tap the file again.
4. Open **ShuttleStats**.

**Always-latest APK:**
https://github.com/Abap92/shuttlestats/releases/latest/download/ShuttleStats.apk

## iOS

iPhone installs are handled separately (TestFlight or ad-hoc) — ask the owner for an invite.
